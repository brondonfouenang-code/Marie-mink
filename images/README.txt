================================================================================
PHOTOS A DEPOSER DANS CE DOSSIER
================================================================================

Le site cherche chaque image ici, dans cet ordre d'extension :
    1. le fichier .jpg
    2. le fichier .webp
    3. le fichier .png

Si aucun des trois n'existe, un placeholder gris s'affiche automatiquement.
Le site fonctionne donc tel quel, sans aucune photo..Depose tes fichiers ici
et ils apparaissent automatiquement, sans toucher au code.

RECOMMANDATION
--------------
- Portrait 4:5 pour les produits (ex. 1200x1500 px)
- JPEG, 80-85% de qualite, moins de 250 Ko par photo
- Nommage strict en minuscules, pas d'espace ni d'accent
